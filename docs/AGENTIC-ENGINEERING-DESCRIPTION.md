Pallet Price Scout — An Agentic Engineering Description

This document takes the mental model from "The Agentic Engineer's Philosophy: Pragmatic Autonomy at Scale" and uses it to describe what Pallet Price Scout actually is. It is not a specification. It is the description of the project when read through that philosophy.

The one-sentence identity of the project is this: Pallet Price Scout is a bounded agentic workflow wearing a deterministic shell. A non-deterministic vision-and-research agent — the installed Pi runtime running the pallet-price-scout skill — is wrapped in hard schemas, evidence rules, and human escalation points so that messy photographic inventory can be turned into labeled, sourced, honestly uncertain price findings, on a localhost machine the human still owns.

The first principle of the philosophy is pragmatic idealism: build backward from a future of full autonomy, but deploy forward at a bounded, high-friction bottleneck today. That is exactly how this project is shaped. The horizon is a workflow-level autonomous appraiser — upload a pallet photo, receive a complete valuation manifest with no human touch at all. The present reality is deliberately narrower and already shipping: one bounded bottleneck, which is to identify the products visible in one photograph, price whatever is verifiable, and refuse whatever is not. The immediate operational yield is real, because the existing skill plus the Python crop and report renderer already produce an interactive HTML valuation artifact today. The project is modular by construction in the way the philosophy demands: the application does not replace Pi's agent, model catalog, authentication, or search — it composes them. When the next generation of vision or retrieval models arrives, Pi upgrades and the application inherits the new capability without a rebuild, because no provider was ever hardcoded. Phase 1 exists as a compatibility spike precisely so that every later phase adds autonomy on top of a working yield rather than instead of one.

The second principle is deterministic foundations for non-deterministic work: treat agentic workflows like distributed systems, with schemas, isolated state, and graceful fallbacks. This project treats the vision model exactly like an unreliable network node. Communication between the browser and the application passes through allowlisted data shapes only — never serialized Pi internals, authentication objects, or environment variables. The browser talks only to the local API, and a single dedicated Node worker owns the Pi runtime over proper IPC rather than parsed stdout. State is isolated so hallucination cannot drift across steps: each analysis run maps to exactly one Pi session file, only one analysis is active at a time while others queue, and the application's own state lives in its database and files, entirely outside the model's context. Fallback paths are built into the honesty of the output: unknown identities, unknown quantities, and unknown prices remain unknown — explicitly rendered as unknown, never laundered into the word verified. When a model cannot advertise image input, the run is rejected at the gate rather than silently misfiring. And the agent is forbidden from extrapolating what it can see to an unseen full pallet. The line in the project's README — unknown product identities, quantities, and prices remain unknown, not verified — is this entire principle compressed into a single sentence.

The third principle is context and evals over ad-hoc prompting: prompting is an implementation detail, and context architecture plus evaluation are the real engineering disciplines. This project follows it in practice. Context is engineered, not improvised: images are EXIF-corrected and normalized, bounding-box crops are extracted, run-specific instructions are appended to a stable skill, and web search is constrained so research stays inside the reasoning loop instead of spawning uncontrolled side windows. The precision, freshness, and relevance of that context are treated as the actual ceiling of the system's capability. Evaluation is treated the same way: parity is measured, not asserted, with compatibility evidence recorded in the docs folder, and a previous photo and report are retained as explicitly unverified regression fixtures — their claimed valuation is a fixture, not a ground truth. The philosophy's rule that anything not automatically measurable cannot be safely deployed is the reason manifest validation and manual correction come before any expansion of trust.

The fourth principle is human escalation and leverage synthesis: the purpose of agentic engineering is to amplify human leverage, not to eliminate the human, moving from human-in-the-loop to human-on-the-loop to systemic agency. This project operationalizes that ladder directly. Today is the human-in-the-loop stage: the routing workspace is literally that gate, where the agent proposes findings and the human routes them as singles or pallets, corrects identities and quantities, and owns the accept-or-reject decision. Structured manifest validation with manual correction is the next phase for exactly that reason. The trajectory is the human-on-the-loop stage: as confidence accumulates, the human moves from reviewing every finding to managing exceptions, and the sorted-findings artifact in the routing view is the first exception-management surface. The invariant across all stages is systemic agency — the agent never silently exceeds its bounds, unknown is surfaced rather than guessed. Even the authority boundary is architectural rather than aspirational: the application is localhost-only, the agent retains the user's own local-machine authority, credentials never leave Pi's own authentication storage, and shared demo tunnels ride the user's own Pi and provider keys. The system knows whose machine it is running on.

Restated as the philosophy's bridge from current reality to future horizon: today the project runs one Pi session at a time in a dedicated worker, invoking a skill with carefully supplied context and delivering progress through durable events, with a human appraising one pallet at a time faster and with honest uncertainty. Tomorrow the same schema-gated, Pi-owned structure composes multiple photos, sessions, and correction loops into a continuous appraisal workflow, backed by a durable organizational memory of items, identities, price evidence, and human corrections that future runs consult instead of re-researching, with regression fixtures promoted into measured ground truth and the human reduced to managing exceptions and strategy.

Finally, the philosophy's personal manifesto, localized to this project: Pallet Price Scout exists at the intersection of a non-deterministic vision-and-research agent and the unforgiving honesty of resale economics. It rejects both the hype of "AI appraises everything instantly" and the skepticism of "AI cannot be trusted with prices." Current models misread labels and invent quantities — and that is precisely why the system is built so that every claim carries evidence, every unknown stays unknown, and every correction routes through a human who owns the machine. Success is not the elegance of the agent architecture. Success is a human who can look at a pallet photo and know, with confidence, which numbers to believe and which ones the machine refused to guess.
